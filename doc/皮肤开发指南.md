# LumiLuna 皮肤开发指南（格式 v1）

本文面向皮肤作者。系统设计全貌见[皮肤系统开发方案书](./皮肤系统开发方案书.md)；这里只讲怎么写出一个能通过导入校验、观感良好的皮肤。

## 快速开始

一个最小的合法皮肤（纯令牌版）：

```json
{
  "formatVersion": 1,
  "manifest": {
    "id": "com.yourname.your-skin",
    "name": "你的皮肤名",
    "version": "1.0.0",
    "author": "你的名字",
    "modes": ["light", "dark"]
  },
  "tokens": {
    "light": { "--md-sys-color-primary": "#005BC1" },
    "dark":  { "--md-sys-color-primary": "#9ECAFF" }
  }
}
```

保存为 `.json`，拖进应用窗口或在「设置 → 外观 → 皮肤 → 导入皮肤」选择文件即可。`src/skins/` 下的四款内置皮肤（墨 / 圆角狂想 / 午夜 / Material Design 1）是四个不同侧面的完整参考实现。

## manifest 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | ✅ | 全局唯一，小写字母/数字/连字符（可点分），2–64 字符。既是升级覆盖的键，也是存储目录名 |
| `name` | ✅ | 显示名，1–32 字符 |
| `version` | ✅ | 语义化版本（`1.0.0`）。同 `id` 重新导入即覆盖更新，会提示版本变化 |
| `author` | ✅ | 1–64 字符 |
| `description` |  | ≤200 字符，鼠标悬停卡片可见 |
| `minAppVersion` |  | 需要的应用最低版本，低于则拒绝导入 |
| `modes` | ✅ | `["light"]` / `["dark"]` / `["light","dark"]`。**只声明你真正适配过的模式** |
| `seedColor` |  | 默认 `false`。一行适配种子色，见下文 |
| `accent` |  | 皮肤列表卡片上的缩略圆点颜色，纯展示用 |

## tokens：结构化令牌（推荐，安全可预期）

按当前模式整套生效：浅色取 `tokens.light`，深色取 `tokens.dark`，两套**相互独立**——缺失的键回落应用默认值（`src/tokens/theme.css`），不做浅→深继承。想全模式一致的令牌（圆角、动效）请在两套里都写。

**白名单**（不在名单内的键会拒收）：

- `--md-sys-color-*` 全部颜色角色（`scrim` 除外——半透明蒙层不能被不透明色顶掉）；
- `--md-sys-shape-corner-*` 全部圆角；值如 `12px`、`50%`；
- `--md-sys-motion-duration-*`（`200ms` 形式）与 `--md-sys-motion-*easing/spring*`（`cubic-bezier(...)` 或关键字）；
- `--md-elevation-1/2/3` 阴影；
- `--lm-scrim-surface`、`--lm-hairline`（毛玻璃表面色与发丝线）。

颜色值支持 `#hex` / `rgb()` / `hsl()` / `oklch()` / `transparent`，禁止 `url()`。**排除项**：`--am-*` 播放器令牌、布局尺寸（`--lm-nav-width` 等）与字号阶梯不在白名单，但任意 CSS 通道仍可覆盖它们。

## css：任意 CSS 注入（表现力最大）

`css` 是一段原样注入全局的样式表（≤256 KB），与 tokens 可同时提供。要点：

1. **浅深适配自己写**：应用在 `<html>` 上维护 `data-theme="light" | "dark"`，照 `theme.css` 的方式用 `[data-theme="dark"] { ... }` 分模式覆盖；
2. **组件 scoped 样式够不到**：Vue scoped 类（如各视图的 `.card`、`.nav-item`）带 `data-v-xxx` 哈希，皮肤选择器匹配不上。可靠的目标是**全局基元类**：`.lm-btn`、`.lm-btn--filled/tonal/text/outlined`、`.lm-icon-btn`、`.lm-glass`、`.lm-skeleton`、`.material-symbols-outlined`，以及元素选择器和 `:root` 变量；
3. **令牌优先**：能用 CSS 变量表达的就别硬编码色值——`var(--md-sys-color-primary)` 一类引用会让皮肤在浅深模式间自动取对色；
4. **远程引用会被警告**：`url()` / `@import` 指向 http(s) 时导入界面会列出全部地址请用户确认（作者可借皮肤收集用户 IP，用户有权知情）。资源请尽量用 data URI；ZIP 打包资源是 v2 能力，`assets` 字段现在必须留空。

## 种子色适配（一行开关）

`manifest.seedColor: true` 后，「设置 → 配色方案」对你的皮肤重新可用：应用会把用户选的种子色生成的整套 MD3 颜色令牌以**内联样式最后写入**，覆盖你的同名令牌。适配姿势：

- 颜色令牌照常提供一套兜底值；
- CSS 里的颜色一律引用 `var(--md-sys-color-*)` 而不是硬编码；
- 圆角/动效/表面等非颜色令牌不受种子色影响，随意发挥。

参考实现：内置皮肤「圆角狂想」（`src/skins/lumiluna.roundify.json`）。

## 单模式皮肤（dark-only 等）

`modes: ["dark"]` 时：激活即自动切到深色并锁定「主题」切换控件，换回默认皮肤后恢复用户原偏好。只声明你适配过的模式——未适配模式不会被兜底渲染，而是被锁住。

## 调试与安全须知

- **坏皮肤逃生**：皮肤把界面改坏时，用 `--safe-mode` 参数启动（如 `LumiLuna.exe --safe-mode`）即可在默认主题下操作设置恢复；
- `formatVersion` 当前恒为 `1`，ZIP 资源包是 v2 规划；
- 皮肤是纯数据（JSON + CSS 字符串），不能执行代码；应用侧校验在 `src/utils/skinSchema.ts`，规则以本文为准；
- 皮肤理论上可影响播放器区域的选择器，但播放器**不在官方支持范围**——版本升级后播放器观感变化不构成兼容性承诺。
