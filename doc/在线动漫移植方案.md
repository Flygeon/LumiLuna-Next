# LumiLuna 在线动漫（番剧）移植方案书

> 版本：v1 · 2026-08-29
> 状态：已评审通过，实施中（Phase 1）
> 范围：把参考项目 Kazumi（Flutter 规则采集在线看番）的核心看番链路移植进 LumiLuna；**仅桌面端，暂不做安卓适配**
> 参考：`在线播放参考/`（Kazumi v2.3.0）、`doc/皮肤系统开发方案书.md`（格式惯例）

## 1. 背景与目标

**参考项目**：Kazumi，核心能力是「自定义 XPath 规则驱动的番剧采集与在线观看」——用户配置规则（JSON，兼容 [KazumiRules](https://github.com/Predidit/KazumiRules) 社区规则），程序按规则抓取番剧站点 HTML → 目录 / 搜索 → 详情 → 分集列表 → 解析出真实视频流 URL → 播放（内置播放器 + 弹幕 + 历史 + 追番）。

**LumiLuna 目标**：设置页新增「在线番剧（实验性）」开关；启用后视频页新增「动漫」子选项卡，具备原项目核心看番能力。

**范围决策**：
- **仅桌面端**（Windows / Linux / macOS），不参与 Android 移植；webview 取流本即桌面能力，移动端自动排除
- Phase 1 = 纯看番链路：目录 / 搜索 → 详情 → 分集 → 取流 → 在线播放 → 历史记录；弹幕、追番放 Phase 2
- 明确不做：DLNA 投屏、Anime4K 超分（GPU 强依赖）、一起看（SyncPlay）、在线更新、验证码自动过验证

## 2. 需求决策记录

| # | 议题 | 决策 | 理由 |
|---|------|------|------|
| D1 | 网络抓取（HTML） | **Rust** 新增 `src-tauri/src/anime.rs`，照 `novel.rs` 模式（reqwest + encoding_rs + UA/自定义 header/cookie） | 番剧站点 URL 是规则任意配置的，前端 `http:` 插件白名单逐站加不现实；Rust 无白名单限制、GBK/Big5 解码可靠 |
| D2 | 规则执行（XPath） | **前端原生 XPath**：`DOMParser` + `document.evaluate` | Chromium XPath 1.0 引擎与 Kazumi 规则语法 100% 兼容；Rust 无 html5ever-DOM 上的成熟 XPath crate（`sxd-xpath` 要 XML DOM，吃不下真实脏 HTML） |
| D3 | 封面图 / 视频直链 | `<img>`/`<video>` 直接加载 http(s) URL，不经过代理 | 媒体元素不受 CORS 限制；CSP 为 null 无阻碍 |
| D4 | 防盗链流（Referer 头） | **本地媒体代理** `anime_media_url`：`http://127.0.0.1:<port>/anime?u=<base64>&h=<headers>`，复用 `webdav.rs` 的 `tiny_http` 代理模式，带 Referer/UA/Cookie 转发、透传 Range | WebView2 的 `<video>` 无法给远端 URL 设自定义头；项目已有同款代理先例 |
| D5 | 规则存储 | app data `rules/` 目录 JSON 文件，Rust 命令做 CRUD（照 `skin.rs` 目录管理模式） | 规则文件支持导入/分享/持久化，独立于 settings.json |
| D6 | 持久化（历史/追番） | **SQLite v4 迁移**（`commands/mod.rs` 的 `SCHEMA_VERSION` + `migrate()` 加分支，照 novel v3 模式） | 与现有 library.db 统一，跨重启保留 |
| D7 | 播放 | HTML5 `<video>` 全屏覆盖层组件 `AnimePlayer.vue`（选集 / 倍速 / 进度） | 与项目现有 `<video>` 一致；m3u8 依赖 WebView2 原生 HLS（风险项，见 §7） |
| D8 | 取流（最大难点） | **webview 兜底一步到位**：Rust `tauri::WebviewWindowBuilder` 建隐藏 webview 窗口加载播放页，`initialization_script` 注入 JS 钩子（Hook `HTMLMediaElement.src` / `fetch` / `<video>`）拦截媒体 URL 回传 Rust。回传双保险：① Tauri event 上报；② 兜底 Rust 轮询 `webview.eval` 读钩子写入的全局变量。**快速路径保留**：静态正则/JSONPath 从播放页 HTML 直接抠直链 | Kazumi 靠无头 webview + JS 注入；Tauri 隐藏 webview + init script 是等价复刻。eval 轮询规避外部页面→Rust 跨域 IPC 不可靠 |
| D9 | 弹幕 | dandanplay API + 前端 canvas 渲染（Phase 2） | 原项目用 `canvas_danmaku`（Dart）；前端画 canvas 弹幕层可行 |

**分工结论**：Rust 负责「抓 HTML / 代理流 / 规则 CRUD / SQLite 持久化 / webview 取流」，前端负责「XPath 求值 / 状态 / UI / 播放」。

## 3. Kazumi 规则数据模型

规则本体 = `Plugin`（`在线播放参考/lib/plugins/plugins.dart`），兼容 KazumiRules 仓库格式。

**顶层字段**：`api`、`type`(anime)、`name`、`version`、`muliSources`(多源)、`useWebview`、`useNativePlayer`、`userAgent`、`baseURL`、`referer`、`usePost`、`useLegacyParser`、`adBlocker`。

**XPath 模式**（`searchMode` / `chapterMode` = `xpath`）：
- 搜索：`searchURL`（含 `@keyword` 占位符）、`searchList`（结果列表 XPath）、`searchName` / `searchResult`（条目名 / 链接 XPath，相对列表节点，链接取 `href`）→ `SearchItem{name, src}`
- 选集：`chapterRoads`（播放线路列表 XPath）、`chapterResult`（剧集列表 XPath，相对线路节点，取 `href` + 文本作集名）→ `Road{name, data[](每集页面 URL), identifier[](每集名)}`

**API 模式**（= `api`）：`searchApiConfig`（request + JSONPath listPath/namePath/sourcePath）、`chapterApiConfig`（request + 嵌套 / 分隔两种选集格式 + `variables` + `episodePage` 模板）。JSONPath 用受限白名单（`$` 开头 + `.` / 索引 / `*` / 引号键）。

**反爬**：`antiCrawlerConfig`（验证码检测：xpath / text / regex + 图片 + 脚本）。

**重要事实**：
- 规则里没有封面 / 简介 XPath——详情元数据（封皮 / 标题 / 简介）来自 Bangumi.tv API，不来自规则
- 字幕不在规则模型里（播放器内嵌处理）
- 内置规则 = `assets/plugins/7sefun.json`、`DM84.json`

**内置规则示例**（api="4" 简版）：
```json
{ "api": "4", "type": "anime", "name": "7sefun", "version": "1.3", "muliSources": true,
  "useWebview": true, "useNativePlayer": true, "userAgent": "",
  "baseURL": "https://www.7sefun.top/",
  "searchURL": "https://www.7sefun.top/vodsearch/-------------.html?wd=@keyword",
  "searchList": "//div[2]/div[2]/div[2]/div[2]/div",
  "searchName": "//div[2]/text()", "searchResult": "//a",
  "chapterRoads": "//div[2]/div[2]/div[2]/div/div[2]/div[1]//div", "chapterResult": "//a" }
```

## 4. 模块拆分

### 4.1 Rust 侧（src-tauri）

`src-tauri/src/anime.rs`（新增，照 `novel.rs` / `webdav.rs` 结构）：
- `anime_fetch`：通用抓取（URL + 自定义 header + charset 嗅探），返回 HTML 字符串
- `anime_media_url`：防盗链流本地代理 URL（复用 `webdav.rs` 的 `tiny_http` 代理，新开 `/anime` 路由，带规则 httpHeaders + Referer 转发、透传 Range）
- `anime_resolve_stream`：取流——先静态提取（正则 / JSONPath 抠 m3u8）；未命中则拉起隐藏 webview + init script 钩子（见 D8），结果经 Tauri event / eval 轮询拿回
- 规则 CRUD：`anime_rules_list / import / save / delete / fetch_remote`
- 持久化：`anime_history_*`、`anime_favorites_*`（SQLite）
- Phase 2：`anime_danmaku`（dandanplay 代理）

`commands/mod.rs`：`SCHEMA_VERSION` 3 → 4，`migrate()` 追加：
- `anime_history(key PK, plugin, anime_id, title, cover, last_episode, episode_page_url, road_index, episode_index, progress_ms, duration_ms, updated_at)`（key = `plugin + anime_id`）
- `anime_favorites(plugin, anime_id, title, cover, added_at, PK(plugin, anime_id))`

`lib.rs`：`pub mod anime;` + 注册新命令。

### 4.2 前端

- `src/utils/animeXPath.ts`：XPath 求值封装（`DOMParser` → `document.evaluate` → 序列化），含 Kazumi 相对节点语义
- `src/utils/animeJsonPath.ts`：受限 JSONPath 求值（照 Kazumi `RestrictedJsonPath` 白名单），供 API 模式规则
- `src/utils/animeRules.ts`：规则 JSON 校验 / 规范化（xpath / api 双模式宽松兼容）
- `src/utils/animeFetcher.ts`：调 Rust `anime_fetch`，缓存 HTML
- `src/utils/animeStream.ts`：静态 m3u8/mp4 直链提取；未命中调 Rust `anime_resolve_stream`
- `src/stores/anime.ts`（Pinia）：规则 / 目录 / 搜索 / 详情 / 选集 / 取流 / 播放 / 历史状态
- `src/components/AnimeOnlineView.vue`：动漫子选项卡根组件（照 `NovelOnlineView.vue` 的 home → detail → player 视图切换）
- `src/components/AnimeDetailPanel.vue`：详情 + 分集列表
- `src/components/AnimePlayer.vue`：全屏播放器（`<video>` + 选集抽屉 + 倍速 + 进度 + 历史上报）
- `src/components/AnimeRuleManager.vue`：规则管理（内置 / 导入 / 启用 / 分享）

**核心数据流**：规则 → `anime_fetch(列表URL)` → HTML → XPath 求值出 `AnimeItem[]` → 详情 `anime_fetch(detailURL)` → `chapterRoads`/`chapterResult` XPath 出 `Road[]` → 选集 → 取流（静态 或 webview）→ `anime_media_url` 本地代理 → `<video>` 播放 + 历史上报。

### 4.3 设置与入口

- `src/stores/settings.ts`：`DEFAULTS` + `fields` 加 `onlineAnimeEnabled: false`
- `src/views/SettingsView.vue`：新增「在线番剧（实验性）」卡片（照「在线小说」卡片）
- `src/views/VideosView.vue`：`videosTab = ref<"local" | "anime">` + 分段按钮（照 `BooksView.vue`）
- `shared/i18n.ts`：zh / en 各加 `settings.onlineAnime*`、`anime.*` 键
- `shared/types.ts`：新增 `AnimeRule / AnimeItem / AnimeDetail / AnimeEpisode / AnimeStream` 等类型

## 5. 阶段划分

- **Phase 1 — MVP 看番链路**：设置开关 + 动漫子选项卡 + 规则引擎（XPath + 受限 JSONPath）+ 内置规则 + 规则 CRUD + 目录 / 搜索 + 详情 + 分集 + 取流（静态快速路径 + 隐藏 webview 鲁棒路径）+ 在线播放（含防盗链本地代理）+ 历史记录
- **Phase 2 — 体验增强**：追番 / 收藏 + 弹幕（dandanplay）+ Bangumi 元数据富化 + 播放器增强（倍速 / 进度 / 选集记忆）+ 字幕
- **Phase 3 — 分享与进阶（可选）**：规则导入导出 / 分享、跨设备同步（复用 WebDAV）、番剧下载、时间表（Bangumi weekday API）、外部播放器

## 7. 风险与对策

- **webview 取流可行性**（最大风险）：隐藏 webview 加载外部播放页时注入脚本时序（`document_start` 前 Hook 完）、外部页面→Rust 回传通道（跨域 IPC 可能被拦）不确定。对策：双通道（event + eval 轮询）；先用已知站点做原型验证再铺开；`useLegacyParser` 类规则走静态提取
- **m3u8 播放**：依赖 WebView2 版本的原生 HLS；风险大则加 `hls.js` 兜底
- **站点反爬**：Cloudflare / JS 渲染站点；webview 取流解一部分，CF 拦截仍可能失败，界面标注「部分源需规则兼容」
- **规则兼容性**：Kazumi 规则 api 版本迭代；前端校验宽松兼容 + 规则分享格式对齐
- **代理安全**：`anime_media_url` 本地代理限定只代理 http(s) 且 host 匹配已启用规则 baseURL（防任意 URL 跳板，照 webdav 的 base_url 校验）
- **合规**：数据 / 缓存 24 小时内清除提示，界面加实验性标注
